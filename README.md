# Nicholas Housain — Personal Website

Live at: https://nick7612.github.io/

Dark automotive-themed portfolio for GitHub Pages.

**Pages:** `index.html` (Home) · `about.html` (About Me) · `projects.html` (Projects)

## Photos
Put all photos in `Photos/` — see `Photos/README.md`.
Example: `<img src="Photos/my-car.jpg" alt="..." />`

## Run locally
```bash
cd "Nicks portfolio website"
python3 -m http.server 8000
# open http://localhost:8000
```

## Deploy
Push to `main` on `Nick7612/Nick7612.github.io` — GitHub Pages serves from `main` / root automatically.
