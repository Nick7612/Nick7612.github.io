# Photos

Put all site photos here.

How to add a photo:
1. Copy your .jpg / .png / .webp file into this folder, e.g. `my-car.jpg`
2. Reference it in HTML as `Photos/my-car.jpg`, e.g.:
   `<img src="Photos/my-car.jpg" alt="My car" />`
3. Commit + push — site updates automatically.

Current files:
- `youtube-profile.jpg` — YouTube channel avatar
- `instagram-profile.jpg` — Instagram avatar
- `headshot.jpg` — (add this to show your photo on about.html)
